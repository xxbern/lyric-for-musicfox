# 歌词静态居中与溢出隐藏开发计划

> **分支**：`fix/lyric-drift`  
> **状态**：已完成 (Completed)  
> **设计目标**：采用基于窗口边界的静态居中排版与溢出截断隐藏机制，确保歌词在任意长度下均保持绝对稳定，彻底消除动态位移隐患。

---

## 一、 架构与排版设计

### 1. 视口排版策略
- **容纳范围内（文本宽度 ≤ 窗口宽度）**：
  - 维持水平垂直双向居中排版：`base-x = (root.width - measure.width) / 2`。
- **超宽场景（文本宽度 > 窗口宽度）**：
  - 采用左边缘对齐（`base-x = 0px`），从首字开始完整呈现文本。
  - 启用外层矩形裁剪容器（`clip: true`），超出窗口右侧物理边界的文本自然截断隐藏。

### 2. 状态机与渲染链路简化
- **Slint 接口解耦**：
  - 移除 UI 层的动态偏移属性驱动，消除每帧推进位移逻辑。
- **生命周期与度量收敛**：
  - `tick` 主循环仅在文本或样式变更时响应一次性度量与重排，避免高频浮点位移计算引入的不确定性。
- **测试用例对齐**：
  - 调整几何与排版相关测试，验证静态居中与超宽左对齐隐藏的几何计算契约。

---

## 二、 改造范围与清单

### 1. UI 呈现层 (`ui/lyric.slint`)
- 封装外层裁剪容器 `clip: true`。
- 将 `base-x` 调整为静态边界判断：`measure.width > root.width ? 0px : (root.width - measure.width) / 2`。
- 移除 `offset-x` 属性及 `scrolling` 动态分支。

### 2. 主循环与状态管理 (`src/window/mod.rs`, `src/window/scroll.rs`)
- 清理主循环内高频跑马灯推进逻辑与 `set_offset_x` 调用。
- 状态机职责转换为纯粹的静态文本度量与对其边界计算。

### 3. 自动化测试 (`tests/scroll_test.rs`)
- 编写静态排版与溢出边界覆盖测试，验证居中坐标与超宽截断契约。
